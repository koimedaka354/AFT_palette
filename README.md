# いきもの日和（旧: ニシアフ・パレット）

小さな生きものたちの飼育方法・道具紹介・計算ツールをまとめる総合サイト「いきもの日和」です。第一弾コンテンツとして、ニシアフリカトカゲモドキ（African Fat-tailed Gecko）の飼育ガイドと、モルフ(品種)交配結果を予測する遺伝計算ツール「ニシアフ・パレット」を掲載しています。

- トップページ(`index.html`)は各ジャンルへの入口。今後さらにジャンルを追加していく想定。
- `nishiafu/index.html` は飼育に必要な道具（楽天アフィリエイトリンク付き）・飼育のポイントを紹介するジャンルページ。
- `medaka/index.html` はメダカの飼育ガイド（準備・日々のお世話・季節ごとの注意点・繁殖）のジャンルページ。飼育方法はnoteのメダカ関連記事を参考にまとめている。楽天アフィリエイトリンクは未設置（今後、楽天アフィリエイト事業側で商品を選定して追加予定）。
- `nishiafu/palette.html` は元々ルートにあったモルフ計算ツール本体。両親のモルフを選択すると生まれてくる子の見た目・確率を計算(通常モード)、欲しいモルフから逆算して親の組み合わせを探すこともできます(逆引きモード)。結果はあくまで統計的な予測であり、実際の交配結果を保証するものではありません。

公開URL: https://koimedaka354.github.io/AFT_palette/ （旧URLの `?p1_xxx=...` 等の共有パラメータ付きリンクは `nishiafu/palette.html` に付け直す必要があります）

## 技術構成

ビルド不要のプレーンHTML/CSS/JSのみで構成されています。フレームワーク・パッケージ管理(package.json等)は使用していません。

- `index.html` — 総合サイトのトップページ。ジャンルカード一覧を表示
- `css/site.css` — トップページ・各ジャンルページ(`nishiafu/index.html`等)で共有するデザインシステム。将来ジャンルページを追加する際もこのCSSを読み込めば同じ見た目になる
- `nishiafu/index.html` — ニシアフリカトカゲモドキのジャンルページ(飼育道具・飼育ポイント・アプリへの導線)
- `nishiafu/palette.html` — モルフ計算ツール本体。UI・遺伝計算ロジックともにこのファイルにインラインで実装（`css/site.css`は読み込まず、従来通り単体で完結）
- `img/` — モルフごとのサムネイル画像、トップページのジャンルカード画像（`card-nishiafu.png`・`card-medaka.png`。代表提供の水彩バナー、2026-08-30差し替え）、`top.png`（ニシアフ・パレットのサムネイル。palette.html・各OGP・nishiafu下部のツール導線カードで使用）
- `scripts/debug_purple.js` — ページには読み込まれないNode実行用のデバッグスクリプト(交配ロジックの動作確認用)
- `.github/workflows/` — 画像自動圧縮などのGitHub Actionsワークフロー

## ローカルでの実行

```bash
python -m http.server 8000
```

またはNodeがある場合:

```bash
npx http-server -p 8000
```

ブラウザで `http://localhost:8000/` を開いて確認してください。

## デプロイ

`main` ブランチにcommit・pushするだけです。GitHub Pagesが `main` のルートから直接配信するため、ビルドや別ブランチへの反映作業は不要です。

`img/` 配下にPNG画像をpushすると、GitHub Actions(`optimize-images.yml`)が自動でpngquantによる圧縮を行い、圧縮後の画像を自動コミットします。
